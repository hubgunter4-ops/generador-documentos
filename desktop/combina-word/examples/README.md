# Ejemplo rápido

Crea un Excel con columnas `NOMBRE`, `IDENTIFICACION`, `DOMICILIO` y `OBSERVACIONES`. En la plantilla Word usa los marcadores `{{NOMBRE}}`, `{{IDENTIFICACION}}`, `{{DOMICILIO}}` y `{{OBSERVACIONES}}`.

Cada fila genera una copia completa de la plantilla y todas las copias se guardan en un único documento final.
